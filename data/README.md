# data/ — 种子用户数据目录

本目录用于存放种子创作者数据文件，例如：

- `merged_creators.csv` — 已验证创作者主档（含销售数据、分类标签）
- `twitter_handles.txt` — Twitter handle 列表
- 其他业务导出数据

## 安全须知

**本目录下的所有数据文件（.csv / .xlsx / .txt 等）均已通过 `.gitignore` 排除，不会提交到 Git。**

如需共享数据文件，请通过以下安全渠道传递：
- 加密压缩包（如 7z 加密）
- 内部网盘 / 企业微信文件
- 数据库直接导入

切勿将真实业务数据提交到版本控制系统。
