## 封面与定位

- **标题**：CraftifyX 业务介绍  
- **定位**：**创作者 IP 情感实体化平台**  
- **一句话**：面向全球的 **「预售验证 + 现货放量」双轮** 模式，将 VTuber、游戏角色、原创 OC 等虚拟 IP 变为收藏级实体商品，使中长尾创作者在**零垫资、低库存风险**下完成 IP 变现。

| 维度 | 内容 |
|------|------|
| 创作者池 | 已合作产生销售约 **150**；签约待上线约 **170**；2026 年目标合作 **420+** |
| 近期业绩 | 近 **3 个月**净预售约 **77 万 RMB**（不含邮费），表述为**主要来自海外** VTuber/OC/游戏工作室 |
| 合同 | 当前 **1 年**独家产品约为主，向 **2 年**过渡 |

| AI | **Miner 1.0** 拟 **4 月底**上线，基于约 **170** 个验证种子，用于跨平台发现与打样资源分配 |

## 经营目标与机会概览（第 2 页）

- **现货**：3 月底正式启动现货业务；4 月起月度预售 SKU 由 **20** 增至 **35**；全年目标上新 **420** 个 SKU。  
- **GMV 目标（保守、不含邮费）**：**9 月**单月超 **140 万 RMB**；**12 月**单月超 **196 万 RMB**。  
- **细分市场**：虚拟 IP/VTuber、OC、厂商 IP、同人二创等——文档给出全球量级、变现痛点（高 MOQ、缺供应链、版权灰区等）及与 CraftifyX 的匹配度。

## 品类与市场洞察（第 3 页）

- **参照**：Funko 等收藏实体市场规模；全球 **Collector Plush** 约 **175–210 亿 RMB**（约 **25–30 亿美元**），年化增速约 **15%**（情感消费驱动）。  
- **CraftifyX 差异**：聚焦**中长尾 IP** 的限量收藏；**21 天预售**、**MOQ 50** 聚单起量；由毛绒向抱枕、挂件、收纳等「软周边」延伸，客单价目标区间约 **175–315 RMB**。  
- **趋势**：Z/Alpha **情感溢价**、成人向 **Kidult** 高增长；算法分发使中腰部 IP 可精准触达，消费从「大牌」转向「圈层身份」。

## 商业模式：验矿 → 采矿（第 4–5 页）

### 验矿（筛选与预售验证）

- **当前**：人工 + 数据分层（约 **150** 个成交案例沉淀规则）。  
- **4 月起**：**Miner 1.0** 自动抓取 X/TikTok/Twitch/Discord 等信号。  
- **远期**：**Miner 3.0** 接入实时销售，用于打样/投放/库存的智能分配。  
- **预售机制**：平台承担打样（周期 **10 / 20 / 30 天** 分档）；**50 件成团**，未成团全额退款；标价约 **210 RMB**，创作者分成短期 **25%**、规模化后 **20%**；3 月预售成团率约 **80%**，目标 **85–90%**。

### 采矿（现货放量）

- **逆向筛选**：仅将预售数据好的款转现货；现货 SKU 上限约为预售 SKU 的 **20%**，以保证约 **6 个月**营运资金安全边际。  
- **增长**：预售期积累开箱 UGC，自然流量占比 **>70%**；投放控制在销售额 **<10%**；验证款 ROAS 可达 **10–15**。

## 增长里程碑与壁垒（第 6 页）

- **2026 年 12 月（保守预测）**：月 GMV **196 万 RMB**、年 GMV **1400 万+ RMB**、合作创作者 **420**、累计 SKU **420**。  
- **2027**：软周边多品类扩张；年 GMV 目标 **7000 万–1.05 亿 RMB**；净利目标 **2100 万–3150 万 RMB**（文档口径）。  
- **收入结构**：现阶段以购销差价为主；**SaaS 订阅、预售服务费、IP 授权**等暂不纳入；**1000+** 创作者规模后再考虑增值服务。  
- **壁垒**：**数据飞轮**（真实案例密度，竞品追赶约 **12–18 个月**）；**柔性打样产能**（月 **50+** 打样，Q4 目标 **70+**）与 **20 天分级打样**体系。

## 创作者锁定与五层飞轮（第 7–8 页）

### 创作者锁定

- 免费打样（单款成本约 **1400–2800 RMB**）形成切换成本；**1→2 年**独家约加深绑定；相对 Kickstarter 等「创作者垫资」模式，强调**零资金风险**全包。

### 现货逆向筛选

- 以预售数据决定备货，周转约 **<45 天**，现金流优于「先备货再卖」。

### 五层闭环（摘要）

1. **柔性供应链**：50 MOQ + 分级打样 → 产能与订单密度正循环。  
2. **全球创作者 AI 挖掘与分级**：Miner **1.0 → 3.0**，S/A/B 分级匹配资源。  
3. **创作者–粉丝社群**：荣誉体系、收藏家编号与标签 → 复购 **10% → 20%+**。  
4. **数字空间增值**：实体 + **数字孪生证书**（轻链上/NFC）、收藏柜、二创展示 → 提升传播与转化。  
5. **数据回流**：销售与复购数据回灌 **Miner**，优化选人、降打样浪费。

**脚注策略**：线下渠道分销、IP 授权运营暂不纳入本飞轮；线下为 **2027 年后**选项，授权暂缓。

## 战略展望与结语（第 9 页）

- **2026**：毛绒收藏级为主，跑通「验矿–采矿」，**420** IP 聚合变现，五层飞轮基建运转。  
- **2027**：**800–1200** 新创作者；抱枕/挂件/毛绒配件等；**限量+编号+直连创作者**；客单价带 **105–560 RMB**；年 GMV **7000 万–1.05 亿**，验证飞轮跨品类复制。  
- **长期愿景**：**创作者 IP 实体化的默认平台**；对标情感消费品领域的 **Shopify** 式基础设施（限量收藏垂直，非泛货架电商）。  
- **结语要点**：已合作创作者 **320+**；一年内从 0 到月销 **77 万**；填补 **IP 供给难变现** 与 **AI 时代用户情感去中心化** 的双重缺口，以**柔性供应链 + 数据筛选 + 社群沉淀**组合切入。
